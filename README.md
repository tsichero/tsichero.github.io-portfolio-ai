Sou Médica Veterinária, especialista em Inteligência Artificial e estudante de Tecnologia em Ciências de Dados. Minha formação combina Medicina Veterinária, Inteligência Artificial para Negócios e desenvolvimento de soluções tecnológicas.

## Como os projetos são estruturados

**Problema → contexto → arquitetura → implementação → avaliação → evidência**

O objetivo é demonstrar não apenas tecnologias utilizadas, mas também decisões técnicas, testes, resultados e limitações. Protótipos, experimentos e serviços preparados para deploy não são apresentados como produtos em produção.
