# Data Analytics — Evidence

This folder contains the reproducible outputs generated from `data/sample_co2.csv`.

- `summary.json`: machine-readable indicators.
- `latest_indicators.csv`: latest-year table.
- `co2_trend.svg`: lightweight visual evidence.

The project script also supports the OWID CO₂ CSV through `--input` or its default URL. The committed evidence uses the local fixture so CI remains reproducible without depending on external network access.
